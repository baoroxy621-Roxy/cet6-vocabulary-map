# 六级词汇思维导图

可在电脑、iPad 和手机浏览器使用的词汇关系图。支持英文或中文搜索、语义主题浏览、同义和近义辨析、反义对照、不同词性的词族关联，以及点词展开、拖动和缩放。

网页及词库均包含在 `index.html` 中，无须安装依赖。

## 数据范围

词汇来源于 [KyleBing/english-vocabulary](https://github.com/KyleBing/english-vocabulary)。六级顺序表去重后包含 3,991 个词，另补充基础关联词。整理关系与自动候选分别标注；自动候选默认关闭。并非全部词条均已逐对核对语义关系。词库原始 BSD 3-Clause 许可保留在 LICENSE 和网页中。

## 发布

在 GitHub 仓库 Settings → Pages 中选择 Deploy from a branch，使用 main 分支的 / (root) 目录。
